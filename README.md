Ubuntu Linux Server Home Lab

Project Overview

This project demonstrates my hands-on experience installing, configuring, and managing an Ubuntu Linux Server using Oracle VirtualBox.

The purpose of this lab is to practice Linux administration, networking, SSH remote access, user management, file permissions, and network troubleshooting.

Lab Environment

Operating System: Ubuntu Server 26.04.1 LTS

Virtualization: Oracle VirtualBox

Server Hostname: linux-server

Network Configuration: NAT

Server IP Address: 10.0.2.15/24

Default Gateway: 10.0.2.2

SSH Port: TCP 22

Host SSH Forwarding Port: 2222

Skills Practiced

Installing and configuring Ubuntu Server

Managing Linux users and groups

Configuring Linux file permissions with chmod and chown

Connecting remotely using SSH

Checking network interfaces and IP addresses

Troubleshooting internet and DNS connectivity

Examining routing tables and default gateways

Checking listening TCP ports

Commands Used

ip a — Display network interfaces

ip route — Display routing information

ping — Test network connectivity

ss -tln — Display listening TCP ports

chmod — Modify file permissions

chown — Change file ownership

systemctl — Manage and inspect services

Project Results

Successfully installed Ubuntu Server, configured remote SSH access, practiced Linux file permissions, and verified network connectivity, DNS resolution, routing, and SSH availability.
